# References

This folder holds the evidence spine for the brain.

Key files:

- `source-ledger.json` records dated sources, source type, confidence, and
  refresh dates.
- `claim-ledger.md` records verified, contested, and practitioner claims.
- `current-requirements.md` summarizes the active source standard.
- `canon/` holds stable reference notes for agent and prompt-operation practice.

Do not add a source to prose only. Record it in the ledger when it affects a
domain claim.
