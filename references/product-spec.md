# Fable 5 Brain Product Spec

## Buyer

AI power users and teams who operate Claude Fable 5 inside Claude Code and need current, cited operating guidance

## Domain

Claude Fable 5 model and Claude Code harness ai operations and source-cited best practices

## Core Workflows

- Answer a Fable 5 capability or limits question with a cited note and an official Anthropic URL
- Diff a new system prompt export against the previous one and file the capability changes
- Design and review Claude Code harness setups such as agents, skills, hooks, permissions, and MCP
- Refresh the research pack from official Anthropic docs, release notes, and engineering posts
- Audit the brain and drive it toward market-ready with the release gate

## Deliverables

- Capability matrix report for Fable 5 model and Claude Code harness
- System prompt diff report between two dated exports
- Operating best practices playbook with dated citations
- Research pack with at least sixty dated citations
- Release-gated market-ready brain package

## Promise

Turn raw sources and recurring decisions into a persistent, source-cited
operating brain.

## Non-Promises

- No claim about Fable 5 behavior without a dated source or a verbatim quote from the export
- Never present folklore or contested guidance as evidence-based
- No irreversible recommendation without owner, confidence, source, and rollback note
- Do not call this brain market-ready unless the audit gate passes
